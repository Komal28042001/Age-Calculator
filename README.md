# Age Calculator

A responsive **Age Calculator** web application built with HTML, CSS, and JavaScript. It supports:

- Mobile and desktop layouts
- Light and Soft Dark mode (with toggle)
- Animations for a smooth UI experience

## Features

- Enter your birth date to calculate your age in years, months, and days
- Mobile-first design, fully responsive
- Auto dark mode based on system preference
- Soft Dark mode toggle for user preference

## Technologies Used

- HTML5
- CSS3 (Flexbox/Grid)
- JavaScript (ES6)
- Google Fonts: [Poppins](https://fonts.google.com/specimen/Poppins)
